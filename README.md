# Grid Fundamentals - CSS Grid Layout

This project demonstrates different CSS Grid layout techniques with examples. The page provides various links to show different grid sizing methods such as Fixed Size, Auto Size, Fractional Size, MinMax Size, and Repeat.

## Features

- **Fixed Size Grid:** Displays items with a fixed width and height.
- **Auto Size Grid:** Allows items to automatically size based on their content.
- **Fractional Size Grid:** Uses fractional units (fr) for flexible grid item sizes.
- **MinMax Grid:** Uses the `minmax()` function to define a range of sizes.
- **Repeat Grid:** Demonstrates the `repeat()` function for repeating grid layouts.
- **Test Grid:** An additional test grid layout for experimentation.

## Technologies Used

- **HTML:** Provides the structure and layout of the webpage.
- **CSS (Flexbox and Grid):** Demonstrates various CSS grid techniques along with basic Flexbox properties for centering content.
